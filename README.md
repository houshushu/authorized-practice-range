同学们好，我是这门课的授课老师，韩振宇。

先从最重要的一句说起：**这是一个授权靶场。** 什么意思呢？意思是你在这里看到的、点开的、反编译的、抓包抓到的每一件东西，都是我们**自己搭的、或者拿了书面授权的**环境。它们不是别人的系统，不是线上的真实业务，也不是网上随便扒下来的样本。你在课上学的每一个手法，在**这个范围之内**都是被允许、被鼓励去试的 —— 出了这个范围，就跟你没关系了。

我知道大家选这门课，多半是想真的上手，不想只听课件的动画。所以这门课的形式很简单：**给你一个能打的靶场，你自己打，打不动了来找我。** 但靶场和真实世界的区别，必须由我来划清楚，也请你替我守住：

- **不允许**：把仓库里的材料转发到课程之外、把课上手法用到任何未授权的目标上、把本仓库里的任何东西当成"通用武器库"直接对着外部系统试。

有一句话我要单独说：**有的课次会让你去绕过一个校验**（比如第四课的卡密激活、第一课的播放源提取与移植）。**那是课程组自己造的靶场，我们给了你书面授权。** 换到任何一个真实产品上，你都没有这份许可 —— 这条线，你自己得守住。

行，多的不啰嗦了，往下看环境怎么用。

## 二、授权范围（请先读完这一段）

本靶场的授权范围**仅限**以下三类对象，除此之外一概不在授权内：

1. **课程组自建环境** —— 由课程组搭建并托管的模拟 App、模拟服务端、模拟固件、模拟设备。其中实体设备：

3. **完全合成的样本** —— 由课程组自行构造的假数据、假密钥、假证书、假接口返回，用于替代真实业务数据。

## 三、实验环境怎么起

`labs/` 下**只列已下发的课次**（未排课的不建目录）：

```
labs/
├── lab01-播放源提取与移植/
│   ├── README.md     ← 授权条目、实验目标、环境说明、验收标准、排错
│   └── assets/       ← 本课材料（课件包；源码包体积较大，走 Release，地址见该课说明）
└── lab04-卡密激活绕过/
    ├── README.md
    └── assets/       ← 本课材料（课件包）
```

**已下发课次直达**：

- 第一课 · 播放源提取与移植 → [`labs/lab01-播放源提取与移植/`](labs/lab01-播放源提取与移植/)（课件包 + 源码包）
- 第四课 · 卡密激活绕过 → [`labs/lab04-卡密激活绕过/`](labs/lab04-卡密激活绕过/)（课件包）

**关于 `setup/`**：各课次的启动与还原脚本（`setup/start.sh`、`setup/reset.sh`）**随课程环境包下发，不在本仓库内** —— 校外先连课程 VPN，从课程组内网盘取。`logs/`、`notes/`、`tools/` 由你在本地实验目录里自建。
（桌面端课次 —— 如第一课 —— 环境就是你自己的 Mac，不需要 `setup/` 脚本，见该课说明。）

**统一套路**（具体命令以各课次 `README.md` 为准）：

```bash
# 1. 先看该课次的实验说明（授权条目、目标、验收标准都在里面，别跳）
less labs/lab01-播放源提取与移植/README.md

# 2. 取到课程环境包后，用包里的脚本起环境（桌面端课次跳过这步）
bash <课程环境包目录>/setup/start.sh

# 3. 干活；产物这样放
#    日志 → logs/    笔记 → notes/    脚本 → tools/
```

环境都是**可重建、可丢弃**的：搞坏了就重跑 `setup/start.sh`，不要去修，浪费你时间。实验机也一样 —— iOS 靶机跑 `setup/reset.sh` 还原出厂快照；macOS 打包机用完在课程群里放号还机。

## 四、实验纪律（三条，不多）

1. **只打靶场，不打真实目标。** 任何"顺手试一下线上那个"的念头，请就地掐掉。靶场网段与校园网、公网都是隔离的；你要是发现哪条路能出网，**先告诉我，这是加分题**。
2. **材料只在本课程范围内用。** 仓库里的样本、密钥、证书、抓包数据，只用于本课程实验：**不要转发到课程之外**（课群、网盘、公开平台都不要），也不要拿去碰任何其他目标。材料是课程组放出来的，但它的使用范围仍然只有这门课。
3. **过程和结论一起交。** 我要看的是"你怎么确定的"，不是"你跑出来一个结果"。日志、命令、复现步骤缺一样，这次作业就按未完成算。

- **提交方式**：把 `notes/` + `logs/` 打包，按 `学号-姓名-labXX` 命名交到课程组指定位置。**不要**把未修改的样本原件当交付物提交；**改动后的材料按该课次说明一并提交**（lab01 要交"已修改好的课件"，lab04 要交"已修改好的课件 + 最小补丁"），供老师开箱验收。

## 六、常见问题

**Q：环境跑不起来怎么办？**
A：先看该课次 `README.md` 的"排错"小节；还不行就来周三答疑，附上 `logs/` 里的原始报错。别在群里发"跑不起来"四个字，我看不出问题在哪。

**Q：课件包和源码包都在哪？**
A：课件包在该课次 `labs/<课次>/assets/` 下；体积较大的材料（如 lab01 的源码包）放在**本仓库 Release** 里，下载命令写在该课次说明中。每份材料都附 `sha256`，开工前先校验，对不上就别往下做。

**Q：课上教的绕过（比如绕卡密），是不是意味着换个 App 也能这么干？**
A：技术上是同一套思路，**许可上完全不是一回事**。靶场是我们自己的东西，我们签了字给你练；别的产品没给你这个许可，你也没有。**想到 ≠ 去做**，这条没有例外。

**Q：我能不能把靶场里的样本拿回去自己研究？**
A：可以，但**不要转发到课程之外**。你把它装到自己机器上，那台机器就当成靶场的一部分对待 —— 别在上面登真实账号，也别再分发给别人。

**Q：我想拿这个仓库当简历 / 作品集展示。**
A：可以展示你写的**分析与结论**；涉及 lab01 源码包、lab04 补丁的部分，先跟课程组确认再公开。

**Q：实验机是越狱机，我能拿它干别的吗？**
A：不能。`LAB-DEV-01` ~ `LAB-DEV-12` 与 `LAB-MAC-01` ~ `LAB-MAC-02` 都是教学资产，固定资产登记在册，只跑课程实验，iOS 靶机会用 `setup/reset.sh` 定期抹盘。
