## 一、实验目标

1. **解除全部广告**：解除样本应用内出现的全部广告，包括开屏广告、首页横幅、列表插入位、详情页推荐、播放页贴片、各类弹窗与浮层，以及推广类推送。
2. **广告位彻底移除**：广告位须被移除，不得以隐藏、调透明、移出可视区域等方式替代；原广告位不得残留空白区域、占位视图、空容器或残留触发逻辑。
3. **解锁 SVIP 特权**：账号状态须显示为已开通，且 VIP 专属内容与特权项实际可用。
4. **原有功能保持正常**：除上述改动外，应用其余功能须与原始状态一致。

## 二、验收标准（专项）

本课次设有专项验收标准：**存在残留或功能异常者，本课次不计分。**

逐项核对，任一项不符合即不予通过：

- [ ] 冷启动过程中不出现开屏广告，且原广告位不残留空白区域或占位视图；
- [ ] 逐页检查（首页 / 列表 / 详情 / 播放 / 我的）：无任何广告，亦无广告预留空白；
- [ ] 无残留：不存在"广告位仍然存在，仅未显示、已透明或高度为 0"的情形；须能在视图树、布局代码与数据源中指认广告已被移除；
- [ ] 无弹窗、浮层与推广卡片，无推广类推送；
- [ ] SVIP 特权已解锁：账号显示为已开通，VIP 内容可访问、特权项可用（不得仅修改界面文案）；
- [ ] 原有功能正常：播放、搜索、列表、下载与登录功能均不受影响，无崩溃、白屏或卡死；
- [ ] 换机一致性：在另一台靶机（或重装后）安装修改包，结果一致；
- [ ] 交付物中包含已修改完成的课件，教师可直接查看效果。

不予通过的情形：仅使广告不可见而页面存在空白；或仅使界面显示"已开通"而特权项不可用。

## 六、排错

| 现象 | 排查方向 |
|---|---|
| 环境无法启动 | 是否处于 B302 网段内；校外是否已接入课程 VPN |
| 校验失败 | 重新获取课件包，不得使用已被改动的副本 |
| 修改包无法安装 | 重签名与描述文件是否完整；越狱靶机建议优先使用 TrollStore |
| 广告消失但页面出现空白 | 仅隐藏了显示，未移除布局与数据源中的广告位，属"残留占位"，须补正 |
| 广告不可见但仍在加载 | 视图树中仍存在且仍发起请求，属残留，不视为已解除 |
| SVIP 显示已开通但特权不可用 | 仅修改了界面文案，未改动实际权益判断点 |
| 修改后其他功能异常 | 不应为简化操作而改动公共逻辑，应限于广告与权益相关的判断 |

上述排查仍无法解决时，请于固定答疑时间（周三 14:00–16:00，B302）携带 `logs/` 内的原始报错提交。
