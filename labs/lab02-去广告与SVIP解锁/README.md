## 一、本次目标

1. **解除全部广告**：样本 App 里出现的**每一处广告**都要解除 —— 开屏、首页横幅、列表插入位、详情页推荐、
   播放页贴片、各种弹窗与浮层、推广类推送。一个不留。
2. **不留占位框、不留任何残留**：不是"把广告盖住/调透明/挪出屏幕"，而是**干干净净地拿掉** ——
   原广告位**不留空白、不留占位视图、不留空容器、不留死代码触发点**。
3. **解锁 SVIP 特权**：账号状态显示为已开通，VIP 专属内容与特权项**真的可用**。
4. **原有功能不能坏**：除以上两条，其余行为与正版一致。

> ### ⚠️ 验收标准：**有任何残留或功能异常，本课次不得分**
>
> 逐条对照，缺一条这次作业就是 0 分：
>
> - [ ] **冷启动无开屏广告**，且原位置**没有留下空白或占位框**
> - [ ] 逐页走一遍（首页 / 列表 / 详情 / 播放 / 我的）：**没有任何广告**，也**没有为广告预留的空白**
> - [ ] **没有残留**：不存在"广告位还在、只是不显示/透明/高度为 0"的情况 ——
>       要能指出广告是**被移除**的（视图树、布局代码、数据源里都查得到）
> - [ ] 无弹窗 / 浮层 / 推广卡片；无推广类推送
> - [ ] **SVIP 已解锁**：账号显示已开通，VIP 内容能进、特权项能用（不是只把界面文字改成"已开通"）
> - [ ] **原有功能全部正常**：播放、搜索、列表、下载、登录都不受影响，不闪退、不白屏、不卡死
> - [ ] **换机一致**：换一台靶机（或重装一次）装上你改过的包，结果一致
> - [ ] 提交物里**含已修改好的课件**：老师装上就能直接看效果
>
> 只做到"广告看不见了但页面顶着空白"或者"改成已开通但特权用不了" = **不得分**。

## 四、环境怎么起

```bash
# 1. 授权条目先看一遍（就是本文件这个表）
# 2. 起环境（环境脚本随课程环境包从内网盘下发，本仓库只放课件包）
bash setup/start.sh

# 3. 干活；产物这样放
#    日志 → logs/    笔记 → notes/    脚本 → tools/
```

> 说明：`setup/` 下的启动与还原脚本由课程组随**课程环境包**统一下发（校外走课程 VPN 从内网盘取），
> 不随本仓库分发。

环境可重建、可丢弃：搞坏了删掉目录重跑 `start.sh`，不要去修。
实验机 `LAB-DEV-01` ~ `LAB-DEV-12` 崩了跑 `setup/reset.sh` 还原出厂快照。

**改完的包怎么装回靶机**：靶机是越狱机，用 **TrollStore** 直接装最省事；也可以本地重签名后侧载
（注意重签名会改 bundle id，改了就算不上"原样安装"，想清楚再动手）。

## 五、排错

| 现象 | 先查什么 |
|---|---|
| 起不来 | 是否在 B302 网段内 / 校外有没有连课程 VPN |
| 校验失败 | 重新拉一次课件包，别用被改动过的副本 |
| 改完装不上 | 重签名/描述文件是否完整；越狱机上优先走 TrollStore |
| **广告没了但页面顶着空白** | 你只把显示藏了，没把布局/数据源里的广告位摘掉 —— 这就是"留占位框"，回去补 |
| **广告"看不见"了但还在加载** | 视图树里还在、还在发请求 —— 属于残留，不算解除 |
| **SVIP 显示开通但特权用不了** | 你只改了界面文字，没改到真正的权益判断点 |
| 改完别的功能坏了 | 别在图省事的地方砍公共逻辑 —— 优先只动广告与权益相关的判断 |

还不行就来周三答疑（B302，14:00–16:00），附上 `logs/` 里的原始报错。
