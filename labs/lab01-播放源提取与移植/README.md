## 一、实验目标

1. 提取课件（教学样本应用）中使用的**全部播放源**，不得仅提取其中任意一个；
2. 将提取到的播放源**全部移植**入本课源码包（`移动应用安全与逆向分析_第一课_源码包_授权靶场.zip`，桌面端工程源码），**全部移植成功方可视为完成**；
3. 移植后的播放源须作为**主播放源**：默认播放须经由该播放源，不得作为备选、兜底或仅在无网络时切换；
4. 使用源码包**打包产出 dmg**，安装后可直接运行。

---

## 二、验收标准（专项）

本课次设有专项验收标准：**打包产出的 dmg 无缺陷方可得分。**

逐项核对，任一项不符合即不予通过：

- [ ] dmg 可正常安装、正常启动，无崩溃、无白屏；
- [ ] **全部**移植后的播放源均可正常播放画面（须逐项验证，不得抽测）；
- [ ] **主播放源生效**：默认播放经由移植后的播放源，须能在代码或日志中指认相应证据；
- [ ] 播放过程无卡死、无报错，控制台无报错堆栈；
- [ ] 换机一致性：在另一台机器（或另一干净用户）下安装同一 dmg，结果一致；
- [ ] 交付物中包含已修改完成的课件，教师解包后可直接查看播放源移植位置（见第三节第 2 项）。

仅提交功能不完整的 dmg 者不予通过。

## 六、排错

| 现象 | 排查方向 |
|---|---|
| `npm install` 卡住或失败 | 是否已接入课程 VPN（靶场网段已放通公共 npm 源）；可改用课程镜像源重试 |
| 校验失败 | 重新获取课件包与源码包，不得使用已被改动的副本 |
| dmg 无法产出 | `npm install` 是否完整；electron-builder 的 mac 目标与机器架构是否匹配 |
| 安装后即崩溃 | 查阅控制台报错堆栈，不得凭推测处理；将堆栈附于答疑提交中 |
| 个别播放源无法播放 | 须同时排查播放源本身与移植完整性两方面 |

上述排查仍无法解决时，请于固定答疑时间（周三 14:00–16:00，B302）携带 `logs/` 内的原始报错提交。
